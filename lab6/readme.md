# лабораторная работа 6
```
Правильная скобочная последовательность обладает важным свойством: каждая закрывающая скобка закрывает самую последнюю из ещё не закрытых открывающих скобок того же типа. Это классический случай применения структуры данных стек.
Идём по строке слева направо:
открывающую скобку кладём в стек,
закрывающую — сверяем с вершиной стека: если совпадает по типу, убираем; если нет (или стек пуст) — последовательность неправильная.
В конце стек должен оказаться пустым.
```

## Почему именно стек?
```
Скобки могут быть вложенными (([{}])) и идти подряд (()[]{}). Простой счётчик открытых/закрытых скобок не справится: он не различает типы скобок и не учитывает порядок закрытия. Стек идеально подходит, потому что работает по принципу LIFO — «последняя открытая скобка должна закрыться первой».
```

1. **Подготовка**

*Создаём пустой стек stack.*
Заводим словарь pairs = {')': '(', ']': '[', '}': '{'} — для каждой закрывающей скобки храним соответствующую открывающую.
Множество opening = {'(', '{', '['} — для быстрой проверки, является ли символ открывающей скобкой.
2. **Проход по строке**

*Для каждого символа ch в строке:*
Если ch — открывающая скобка → stack.append(ch).
Если ch — закрывающая скобка:
Если стек пуст или stack[-1] != pairs[ch] → возвращаем False.
Иначе → stack.pop().

3. **Финальная проверка**

*После обработки всех символов:*
Если стек пуст → True (все скобки корректно закрыты).
Иначе → False (остались незакрытые открывающие скобки).
