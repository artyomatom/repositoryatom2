# Лабораторная Работа 1

## Реализовать следующую задачу:

```
у нас есть поле 4х4 всего 16 клавиш
игра идет по раундам t = 1,2,3 и т.д
в раунде нужно нажать все клавиши с цифрой раунда t

мы имеем 2 игрока, каждый может нажать К клавиш. Значит вдвоем они нажмают Кх2 клавиш
```

```
условие получения балла

если на поле нет кнопок с цифрой t - нет балла

если кнопок с цифрой t от 1 до kх2 включительно - 1 балл

если кнопок больше чем Кх2 - игроки не успевают нажать все, соответственно - балл не дается
```

# Алгоритм решения

```
мы считаем число К и вычисляем макс кол-во кнопок

max_keys = k * 2

считаем 4 строки поля перебором

считаем сколько раз каждая цифра встречается на поле.

самое главное:

если цифра встречается на поле хотя бы 1 раз и ее количесво <= max_keys прибавляем + 1

далее вывожу общий счет
```


```
for _ in range(4):
  row = input()
```

range генерирует числа

для каждого из 4х мы выполняем условие

введите строку

```
for char in row:
  if char != '.':
    counts[char] += 1
```

char - взял первый символ строки назвался собой и выполнил код. далее для всех символов также

те мы проверяем точка символ или нет

каждый код выполнится 16 раз так как у нас 2 цикла внешний и внутренний

```
counts = {str(i): 0 for i in range(1, 10)}

```

это генератор словаря.

counts = {} - пустой словарь (в нем нет ни одного ящика)

for i in range (1, 10): - i принимает значения от 1 до 9

key  = str(i) превращаем число в строку 1 - '1'

counts[key] = 0



### подробнее про словари

это короба с ящиками

у каждого ящика есть имя и содержимое

синтаксис: имя_словаря[ключ] = значение
counts['1'] = 0 положили 0 в ящик с именем 1
после этого словарь выглядит примерно так:

counts = {'1': 0, '2': 5}

```
for i in range(1, 10):
  key = str(i)
  counts[key] = 0
```

key = str(i) превращаем число в строку

дале мы сохраняем эту строку в переменную key

так удобнее ведь ключи тоже должны быть строками
