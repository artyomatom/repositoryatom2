# лабораторная работа 5
```
Чтобы проверить, является ли фраза палиндромом, не обязательно строить новую строку (удалять пробелы, приводить регистр). Достаточно использовать два указателя: один идёт с начала строки, другой — с конца. Они движутся навстречу друг другу, пропуская все «лишние» символы (знаки препинания, пробелы) и сравнивая только значимые символы (буквы и цифры) в нижнем регистре.
Это даёт решение за O(N) по времени и O(1) дополнительной памяти (если не считать приведения строки к нижнему регистру).
```

Почему именно два указателя?
Альтернативный подход — сначала отфильтровать строку (оставить только буквы/цифры, привести к нижнему регистру), а потом проверить, равна ли она своему перевёрнутому варианту. Это тоже O(N), но требует дополнительной памяти под новую строку.
Метод двух указателей:
Работает в один проход по строке (каждый символ просматривается максимум один раз).
Не создаёт новых строк.
Останавливается досрочно, как только найдено первое несовпадение.

1. **Подготовка**

Считываем всю входную строку и приводим её к нижнему регистру (s.lower()), чтобы не думать о регистре при сравнении.

2. **Инициализация указателей**

left = 0 — указатель на начало строки.
right = len(s) - 1 — указатель на конец строки.

3. Основной цикл (пока left < right)

Сдвигаем left вправо, пропуская все символы, которые не являются буквами или цифрами (not s[left].isalnum()).
Сдвигаем right влево, пропуская все не-буквы и не-цифры справа.
Если left < right (указатели ещё не встретились):
Сравниваем s[left] и s[right].
Если не равны → выводим False и завершаем работу.
Если равны → сдвигаем оба указателя: left += 1, right -= 1.

4. **Результат**
Если цикл завершился без несовпадений — выводим True.
