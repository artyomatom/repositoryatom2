# лабораторная работа 4

```
Для каждого участка улицы нужно найти расстояние до ближайшего нуля (пустого участка). Ноль может находиться как слева, так справа от рассматриваемого участка. Значит, нам нужно знать оба расстояния и выбрать минимальное.
Ключевая мысль: если мы будем идти по улице в одном направлении и просто запоминать индекс последнего увиденного нуля, то для каждого участка мы мгновенно узнаем расстояние до нуля с одной стороны. Чтобы узнать расстояние и с другой стороны, достаточно пройти по улице в обратном направлении.
```

```
Но. Один проход не даёт полной информации:
Если идти слева направо — мы знаем расстояние до ближайшего нуля слева, но не знаем, есть ли ноль справа (и насколько он близко).
Если идти справа налево — знаем расстояние до нуля справа, но не слева.
Два прохода решают эту проблему: после первого прохода у нас есть расстояния слева, после второго — мы сравниваем их с расстояниями справа и берём минимум.
```


1. Чтение данных

Считываем длину улицы n и массив из n чисел (номера домов и нули).

2. Первый проход (слева направо)
Создаём массив ans размера n.

Заводим переменную **last_zero = -1** — индекс последнего встреченного нуля.

Идём по массиву слева направо:

*Если текущий элемент = 0:*
**обновляем last_zero = i**
*записываем ans[i] = 0*
Иначе (элемент ≠ 0):

*Eсли last_zero != -1 → ans[i] = i - last_zero*
**иначе → ans[i] = n (заглушка: нуля слева ещё не было)**

3. Второй проход (справа налево)

Снова заводим last_zero = -1.

Идём по массиву справа налево:

Если текущий элемент = 0:
обновляем last_zero = i

Иначе:
если last_zero != -1:
считаем dist = last_zero - i
если dist < ans[i] → обновляем ans[i] = dist

4. Вывод результата
Печатаем массив ans через пробел в одну строку.
